# hi-resume

一个本地优先的个人简历管理工具：维护一份主简历，并基于不同公司和职位快速创建多个岗位版本。

产品交互参考 FlowCV 的“表单编辑 + 实时预览”模式，但重点放在岗位版本管理，而不是模板数量或在线服务。

## 核心概念

```text
主简历 Master
├── 岗位版本 A：只覆盖简介、技能顺序和部分经历
└── 岗位版本 B：只覆盖项目顺序和部分经历
```

岗位版本默认继承主简历；只有明确修改的字段才保存为覆盖值，并可以随时恢复为主简历内容。

## MVP 目标

MVP 需要支持以下闭环：

1. 创建和编辑主简历；
2. 创建多个岗位版本；
3. 在岗位版本中调整字段，并实时查看预览；
4. 导出可投递的 PDF；
5. 导入、导出 JSON 作为本地备份。

## 设计约束

- 默认无账号、无后端、无网络依赖；
- 数据保存在本机，并提供显式备份和恢复；
- MVP 只实现一个稳定、ATS 友好的模板；
- AI 改写、ATS 评分、云同步和在线分享不属于 MVP。
