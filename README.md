# hi-resume

一个本地优先的个人简历管理工具：维护一个素材池和一份主简历，针对不同 JD 快速生成岗位版本，并跟踪每次投递的进展。

产品交互参考 FlowCV 的「表单编辑 + 实时预览」，但重点在岗位版本管理和投递追踪，而不是模板数量或在线服务。

## 核心概念

```text
条目池：所有经历、项目、bullet、技能，每个有稳定 ID
  ├── 主简历：一份选择清单 + 顺序，可直接投递
  └── 岗位版本 A：换进两个项目、关掉几条 bullet、改写简介 + 投递记录
      岗位版本 B：调整技能顺序、隐藏语言区块 + 投递记录
```

岗位版本默认继承主简历的内容选择。针对 JD 的调整以「选哪些、什么顺序、隐藏什么」为主，只有个人简介和 bullet 文本需要改写。每个岗位版本同时是一条投递记录。

## 路线

按里程碑推进，每一步结束时都能真正用起来：

1. **M1 一份主简历**：从零建立主简历，区块可增删改排序，实时分页预览，导出 PDF 与 JSON；
2. **M2 素材池与岗位版本**：条目池、版本继承与针对性调整；
3. **M3 投递追踪**：状态、事件、下一步动作与首页看板；
4. **M4 Markdown 导入**：结构稳定后再做的一次性导入脚本。

数据结构从 M1 起就按完整模型建，避免加版本时重写数据层。

## 设计约束

- 默认无账号、无后端、无网络依赖；
- 数据保存在本机，并提供显式备份和恢复；
- MVP 只实现一个稳定、ATS 友好的模板；
- 追踪只做手动记录，不碰邮箱、爬虫和后台通知；
- AI 改写、ATS 评分、云同步和在线分享不属于 MVP。
